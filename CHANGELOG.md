# Historique des versions

Chaque version correspond à un tag Git (`git checkout ux18i-<lot>`).

| Tag | Contenu |
|---|---|
| `ux18i-base` | Base gelée UX18I_ACCESSIBILITE_OK |
| `ux18i-A` | Retrait du jargon de production ; sources en accordéon ; doublons supprimés |
| `ux18i-D` | Typographie (17 px, interligne 1,6) ; pictogrammes des défis ; repères à emporter en cartes |
| `ux18i-C` | Grammaire commune : 6 repères, clôture type, apports avant les simulateurs |
| `ux18i-BE` | Personnages Maëva / Thomas / Léon ; choix de profil S2 mémorisé ; interactions réversibles |
| `ux18i-F` | Corpus S2 réintégré au mot près |
| `ux18i-G` | Corpus réintégré dans tout le module ; références scientifiques visibles (75 écrans) |
| `ux18i-H` | Portraits de Léon apaisés ; visuels des nouveaux écrans |
| `ux18i-I` | Nouvelles pastilles Thomas et Maëva ; 4 bandeaux de situation illustrés |
| `ux18i-J` | 8 écrans repères identiques par séquence ; chemin de séquence ; « Le modèle à retenir » |
| `ux18i-K` | Allègement : défis resserrés (32 → 18 questions), repères « En bref », contrastes AA |
| `ux18i-L` | Fusion d'écrans (75 → 62) ; contenus secondaires repliés ; durée ~3 h |

| `ux18i-N` | Simulateur v2 sur S3 et S4 ; écrans « conséquences » intégrés (59 écrans) |
| `ux18i-O` | Guide en quatre postures (explique, questionne, alerte, félicite) |
| `ux18i-P` | Correctifs bloquants : complétion SCORM, caractères parasites, navigation unique |
| `ux18i-Q` | Positionnement de sortie en 3 étapes ; titres de séquence uniques ; saisies facultatives ; jargon retiré |
| `ux18i-R` | Finitions : plan d'action, menu aligné sur les titres, pastilles, bilan « il vous reste » |
| `ux18i-S` | Bandeau d'ouverture S1 dédié |
| `ux18i-T` | Défis en « carnet de mandat » (accueil et tableau de bord, carnet imprimable) |
| `ux18i-U` | En-tête de repérage unique : séquence, position, frise des 6 étapes |
